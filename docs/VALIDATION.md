# 검증 상태 · 2026-11-03

환경: Windows, Python 3.15.0 (64비트), Tk 9.0. 로컬 검증 결과이며 GitHub CI 실행 결과와 구분합니다.

## 완료

- Python 전체 소스 및 Pico Python 소스 문법 검사.
- 자동 테스트 **27개 통과**: 수식 제한, 그래프 오류, 모의 실행, 조건 분기, 반복/변수, 최소 지연, 가우시안 하한, 곡선 종점, 좌표 모드, 취소, 대상 유실/가림, 사용자 입력 양보, 단계 한도, Python opt-in, 시리얼 ACK/오류/STOP/수렴 실패.
- Windows ctypes 구조체 크기 검증: INPUT, RAWINPUTHEADER, RAWMOUSE, RAWKEYBOARD, Job Object 구조체.
- Windows 실제 Job Object를 닫아 잠든 자식 프로세스가 종료되는지 확인. 테스트는 최대 2초 안의 종료를 확인하며 실제 비상 정지 단축키의 종단간 지연 측정은 아닙니다.
- GUI 실행 및 화면 확인, 독립 감시 프로세스 초기화 완료 표시 확인.

초기 테스트 1개는 실행 환경의 임시 폴더 쓰기 권한 때문에 실패했고, TEMP/TMP를 쓰기 가능한 작업 폴더로 지정한 후 모두 통과했습니다. 앱 자체에 임시 폴더 경로를 하드코딩하지 않았습니다.

화면 조작 검증은 사용자가 Escape로 중단하여 종료했습니다. 이후 화면 입력을 추가로 수행하지 않았습니다. 작은 화면에서 블록 목록이 잘리는 것을 발견하여 스크롤을 추가했으며, 이 수정 이후에는 다시 화면을 조작하지 않았습니다.

## 미완료 / 배포 전 실기 검증 필요

- 실제 전역 핫키 → 실행 중 worker 종료까지의 지연 측정.
- 실제 마우스/키보드 Raw Input과 실제 MCU 장치 제외 검증.
- 실제 SendInput 클릭과 USB HID 클릭의 종단간 동작.
- Arduino 컴파일/업로드, Pico 설치, 물리 정지 버튼과 watchdog 실기 동작.
- 100/125/150/200% DPI, 음수 원점 다중 모니터, 창 이동/크기 변경.
- 대상 crash/최소화/포커스 전환/오버레이 가림에 대한 실제 앱 검증.
- 최대 500개 블록, 장시간 반복, CPU 부하 상황, 원격 데스크톱.
- 클릭 CPS, CPU 사용률, 메모리, P50/P95/P99 지연의 장시간 측정.
- GitHub CI의 Python 3.11/3.14 및 Linux 매트릭스 실행 결과.

## 수동 점검 순서

1. 외부 동작이 없는 전용 테스트 창을 띄우고 짧은 이동→클릭→종료 흐름을 만듭니다.
2. 모의 실행으로 좌표와 연결을 확인합니다.
3. 실제 입력을 켜고 실행 중 전역 핫키, F12, 정지 버튼을 각각 검사합니다.
4. 대기/곡선 이동/클릭 반복 중 사용자가 마우스·키보드를 사용했을 때 제어권 양보를 확인합니다.
5. 대상 창을 닫거나 최소화하거나 다른 창으로 전환했을 때 즉시 중단되는지 확인합니다.
6. UI 및 worker를 각각 비정상 종료했을 때 나머지 입력이 이어지지 않는지 확인합니다.
7. MCU를 사용할 때 USB 분리, ACK 유실, 물리 정지 버튼, 잘못된 장치 선택을 별도로 검사합니다.

모든 결과는 설정/OS/보드 버전과 함께 기록하세요. 단위 테스트 결과만으로 실제 장치의 안전 동작이나 높은 성능을 보장할 수 없습니다.
