# 검증 상태 · 0.2.0

2026-11-03, Windows / Python 3.15.0 64비트 / Tk 9.0에서 확인했습니다.

## 확인한 내용

- 자동 테스트 **31개 통과**. 유효·잘못된 설정, 정확한 반복 횟수, 중지할 때까지 반복/취소, 실제 입력 없는 테스트, 최소 간격, 대상 유실/가림, 물리 입력 양보, 시간 한도, DPI/비율 좌표, 대기 중 창 이동, 시리얼 ACK/STOP/수렴 실패를 포함합니다.
- 자동 대상 선택의 foreground identity, 자기 앱·바탕화면 거절 검증.
- Win32 구조체 크기 및 실제 Job Object에 의한 비협조 자식 프로세스 종료 검증.
- Python 소스 문법 검사.
- 입력 엔진을 끈 실제 Tk 앱의 기본 화면을 렌더링해 육안 확인.
- 기본 자동 대상, 유한/연속 반복, 위치 지정 펼치기, 실행 중 설정 잠금, 새 시작/중지 메시지 형식, 추가 설정 창을 앱 내부에서 검증.

UI 점검은 `AutoClicker(root, start_services=False)`로 수행했습니다. OS에 클릭을 주입하거나 사용자의 다른 창을 조작하지 않았습니다. 화면 미리보기의 시작 버튼은 의도적으로 비활성화되어 있습니다.

## 아직 확인하지 못한 내용

- 실제 정지 키 → 실행 프로세스 종료까지의 종단간 지연.
- 실제 Raw Input·SendInput 클릭 및 MCU 장치 제외 동작.
- 보드 컴파일/업로드, USB 분리·watchdog·물리 정지 버튼 실기 동작.
- 여러 DPI/모니터 조합, 독점 입력 프로그램, 장시간 부하, CPU/CPS/지연 측정.
- 이번 커밋의 GitHub CI 결과는 로컬 결과와 별도로 확인해야 합니다.

## 실제 입력 점검

1. 외부 동작이 없는 테스트 창에서 반복 횟수 3회부터 시작합니다.
2. 자동 대상과 명시적 대상 각각에서 시작·완료·중지를 검사합니다.
3. F12 / Ctrl+Alt+Shift+K / 중지 버튼을 각각 검사합니다.
4. 물리 마우스·키보드 개입, 창 종료·최소화·포커스 전환·가림을 검사합니다.
5. 위치 지정을 켜고 DPI와 창 위치·크기 변경을 검사합니다.
6. USB 보드를 사용할 때는 하드웨어 문서의 실기 점검표도 수행합니다.
