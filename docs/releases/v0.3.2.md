# ArcMouse 0.3.2

Windows x64 executable builds are now available alongside the source code.

## Downloads

- **ArcMouse-0.3.2-windows-x64.exe**: single-file app. No Python installation is required.
- **ArcMouse-0.3.2-windows-x64.zip**: the same app with the README and third-party license notices. Extract the ZIP and run `ArcMouse.exe`.
- **SHA256SUMS.txt**: checksums for both downloads.

The interface is English. Start with F6 and stop with F7, or configure your own shortcuts. Current-cursor clicking, point sequences, per-action waits, holds, slides, and existing version 3 profiles are supported. The executable includes pySerial for optional USB board mode; board firmware must still be installed separately.

The build runs without requesting administrator privileges. It is not code-signed, so Windows may display an unknown-publisher warning.

## Validation

The Windows build workflow runs the source tests and then launches the packaged EXE in a dry-run self-test. This checks Tk startup, independent hotkey monitoring, frozen worker processes, Job Object containment, cursor and point sequences, cancellation, and shutdown. It does not generate mouse clicks or validate a physical MCU board.
